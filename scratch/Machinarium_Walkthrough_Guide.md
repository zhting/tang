# 《机械迷城》（Machinarium）全关卡极速通关与密码指南

这份指南为你整理了经典解谜游戏《机械迷城》中最核心的通关密码、核心机关解法以及全关卡极速图解步骤。

## 一、 核心关卡密码锁答案

如果你在游戏中卡关，以下是两个最常被查阅的固定密码：

*   **牢房密码锁：`4:45`**
    *   **触发方式**：在监狱救出队友后，进入监控室点击开关把灯关掉，墙上的时钟表盘就会显示出荧光的夜光时间。回到最左侧的牢房电梯旁，输入该密码即可开启。
*   **最后一关楼顶电梯（收音机调频）密码：`1423523`**
    *   **触发方式**：在游戏大结局前，将大头科学家房间的黄色屏幕仪器坐标调到 **`7.0 : 108`** 会听到一段音乐。离开房间走到外面的电梯电路板旁，根据音高按顺序按下按钮，对应的密码按键顺序为 **`1-4-2-3-5-2-3`**。

## 二、 全关卡极速通关步骤（按图索骥）

| 关卡编号 | 关卡场景名称 | 核心通关操作 |
| :--- | :--- | :--- |
| **01** | **垃圾场 (Discarica)** | 组装身体，利用磁铁和绳子荡到右侧离开。 |
| **02** | **吊桥 (Ponte levatoio)** | 染上蓝色圆锥帽、叠起帽子伪装成守卫，拉动响铃。 |
| **03** | **炉房外护城河 (Fossato)** | 将控制杆调整为 **2A**，拿到黄色道具后利用控制轮滑过去。 |
| **04** | **锅炉房 (Caldaia)** | 将熔炉开关 **1、3向下，2向上**。接着将线路交叉对调（红黑互换）。 |
| **05** | **监狱/牢房 (Prigione)** | 揉干草做香烟换取线索；拿走钥匙；将时钟密码设定为 **`04:45`**。 |
| **06** | **机械狗 (Cane)** | 用油枪引出机械狗，用马桶吸盘枪抓回，交给妇人换取雨伞。 |
| **07** | **酒吧下棋 (Sfida)** | 在酒吧里赢下**五子棋**拿到螺丝，顺便顺走粘蝇纸。 |
| **08** | **乐团 (Banda)** | 将螺丝给萨克斯手，用粘蝇纸抓苍蝇塞进乐器逼出管道里的猫。 |
| **09** | **大广场 (Piazza)** | 将大钟时间调到 **`VII 和 倒∞（无限大符号）`**，拿到油壶。 |
| **10** | **外壁电梯 (Ascensore est.)** | 冻结/融化水管；对着风扇故意**全部答错**让它超载自毁。 |
| **11** | **温室 (Serra)** | 解开激光开关谜题，拿到放大镜，并在窗前复刻蝴蝶翅膀图案。 |
| **12** | **游乐场 (Gettone)** | 榨取向日葵油；玩小游戏通关赢取硬币，买走电池。 |
| **13** | **室内大电梯 (Ascensore)** | 电梯灯泡连线密码顺序：**`1-6-3-2-7-1`**。 |
| **14** | **拆除炸弹 (Bomba)** | 依次解开吸尘器/剪刀解谜，最终剪断顺线：**D - B - E - A - C**。 |
| **15** | **大脑电梯 (Ascensore 2)** | 电梯灯泡九宫格密码顺序：**`1-4-7-2-5-8-3-6-1`**。 |
| **16** | **顶楼天台 (Cupola)** | 用喷雾和锤子砸开锁，收音机调频并按琴键密码：**`1-4-2-3-5-2-3`**。 |
